# Auditoria de bugs — 16/11/2026

Varredura completa feita com o sistema rodando (MongoDB 9.0.4 local, banco descartável `faltas_teste_claude`, fuso `America/Sao_Paulo`), duas revisões estáticas (backend e frontend) e teste das telas no navegador. A reprodução de cada item é uma verificação do roteiro `npm run test:e2e` ou dos testes `npm test`; o código anterior passava em 52 das 82 verificações do roteiro e o atual passa em todas. Nada foi commitado nesta auditoria.
